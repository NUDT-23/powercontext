# PaperLens 试用说明（一页版）

## 这是什么

PaperLens 是一个科研文献工作台：把**语义检索 + 关键词检索 + 年份/来源过滤**放在同一次查询里，用长期记忆记住你的阅读偏好，并能把多篇论文生成「问题—方法—数据—结论—局限」对比和带 `[P#]` 引用的综述初稿。

本次是真实任务试用，不是考试，也不评价你的能力。

## 你需要做什么（约 20–30 分钟）

1. 用组织者发给你的链接打开，例如 `http://192.168.220.55:8080/?u=U01`，确认右上角编号是你的。
2. 用平时习惯的工具完成 3 个基线任务，组织者会计时。
3. 在 PaperLens 里做同样的 3 个任务：
   - **任务 A**：找出 2025 年及以后、与 LLM Agent 记忆或评测相关的 3 篇论文
   - **任务 B**：选 3 篇，生成方法对比
   - **任务 C**：写一段 300–500 字综述初稿，导出 Markdown
4. 对至少 3 条检索结果点「相关 / 不相关」。
5. 填写匿名问卷（约 3 分钟）。

任务 A 会分别关闭、开启“长期记忆”各跑一次，用来对比差异。

## 你需要准备

- 一台能连现场 Wi-Fi 的电脑或手机
- 平时找文献的方式（Google Scholar / arXiv / 知网等）用于基线任务
- 不需要注册账号，不需要提供姓名、学号、手机号或邮箱

## 隐私说明

- 应用只记录 `U01` 这类编号、检索/综述操作、耗时和反馈，不记录姓名与联系方式。
- 问卷匿名，第一题可选择“不同意将匿名数据用于比赛材料”；选不同意也可以正常参加。
- 现场如需拍照或录屏，会避开你的屏幕和个人信息；如不希望出镜请直接告诉我们。

## 请这样操作

- 按你平时的习惯做，不要为了“配合”而故意加快或夸大。
- 遇到不会点的按钮可以问，但不会提示答案。
- 卡住超过 3 分钟直接告诉我们，可以跳过并记录。
- 觉得不好用、找不到、生成得慢，都请如实填写，这比夸奖更有价值。

## 结束后

- 把计时表交给组织者
- 确认问卷提交成功
- 可以随时向组织者补充建议

谢谢参与！
