# 《老板记性太好酒馆》运行说明

> Dify 赛道作品 · Just for Fun。Dify Chatflow + **PowerContext**（记忆核心）+ MiniMax LLM。
> 交付物：`DSL/tavern.yml`（本说明同级目录）、`验证样例.md`。

## 1. 作品结构

一个 Dify **Chatflow（advanced-chat）** 应用，5 个节点线性串联：

| 节点 | 类型 | 作用 |
|---|---|---|
| 开局登记 | start | 表单收集 `player_key`（玩家名，跨会话记忆钥匙） |
| 老板回忆中 | http-request | `POST {PC_URL}/v1/memory/search` 召回相关记忆 |
| 老板 | llm | 人设 system prompt + 注入记忆 + MiniMax-M3.1-Flash |
| 直接回复 | answer | 流式输出老板台词 |
| 老板记下了 | http-request | `POST {PC_URL}/v1/memory/remember` 写入本轮对话 |

**PowerContext 的作用（可核对）**：每次对话先 search 后 remember，全部记忆（玩家说过的话、老板的回应）持久化在 PowerContext 服务端；服务重启、Dify 会话重建后记忆仍在。Dify 工作流的节点执行记录可直接核对两次 HTTP 调用（状态码 200、返回体、耗时）。

## 2. 环境要求

- Docker + Docker Compose（Dify 1.11.x 自部署，`docker/entrypoint` 标准安装）
- Python 3.11+（PowerContext Server）
- 模型：任一 OpenAI 兼容 Chat API（我们用 **MiniMax MPlan**：`https://api.minimaxi.com/v1`，模型 `MiniMax-M3.1-Flash`；换成其它兼容端点也行）

## 3. 部署步骤

### 3.1 启动 PowerContext Server

```bash
git clone https://github.com/oceanbase/powercontext.git && cd powercontext
uv sync --locked          # 或按官方文档安装
# 本机 Docker 网络内可达需绑 0.0.0.0（容器经网关 172.17.0.1 访问）：
POWERCONTEXT_SERVER_ALLOW_UNAUTHENTICATED_NON_LOOPBACK=true \
  uv run powercontext server run --host 0.0.0.0 --port 8000 --no-env-file
# 验证：
curl http://127.0.0.1:8000/health/live   # {"status":"ok"}
```

### 3.2 创建酒馆 scope（拿到 scope_id）

```bash
curl -X POST http://127.0.0.1:8000/v1/scopes \
  -H 'Content-Type: application/json' \
  -d '{"title":"Tavern","summary":"酒馆玩家记忆","idempotency_key":"tavern-1"}'
# 返回 {"scope_id":"scp_xxxxx...","title":"Tavern",...}  ← 记下 scp_xxx
```

### 3.3 启动 Dify 并导入 DSL

```bash
# 按官方 docker compose 安装（github.com/langgenius/dify），浏览器打开 http://localhost
# 初始化管理员 → 进入工作室 → 「导入 DSL 文件」→ 选择 DSL/tavern.yml
```

### 3.4 配置模型

设置 → 模型供应商 → 安装 **OpenAI-API-compatible** 插件 → 添加模型：

| 配置项 | 值 |
|---|---|
| Model Name | `MiniMax-M3.1-Chat`（或当前可用的 MiniMax 模型，`GET /v1/models` 查询） |
| Model Type | LLM |
| API Key | `<你的 MiniMax API Key>`（占位，勿提交真实值） |
| API endpoint URL | `https://api.minimaxi.com/v1` |

### 3.5 设置环境变量（导入后必做）

应用编排页右上「环境变量」，把 DSL 自带的两个占位值改为实际值：

| 变量 | 值 | 说明 |
|---|---|---|
| `PC_URL` | `http://172.17.0.1:8000` | PowerContext 地址；Dify 跑在 Docker 里时用网关 IP；同机直跑 Dify 用 `http://localhost:8000` |
| `TAVERN_SCOPE` | 3.2 步返回的 `scp_xxx` | 酒馆记忆 scope |

### 3.6 发布

右上角「发布」→「更新」，然后在「预览/探索」中开聊。

## 4. 体验入口

- 预览页输入名字开始对话；**开新会话再回来**，老板仍记得之前说过的话（跨会话记忆是核心玩法）。
- 已知限制：记忆检索为 FTS 关键词匹配（PowerContext 未配 embedding 模型时自动降级）；玩家名即身份键，重名会共享记忆（这也是个乐子）。
