技术说明

          

            本应用把文档切分与 embedding 放在浏览器内完成：模型为
            Xenova/bge-small-zh-v1.5（512 维，CLS pooling + L2 归一化），
            通过 Transformers.js + ONNX Runtime Web 加载。优先使用 WebGPU + FP16，
            不可用或初始化失败时自动降级到 WASM + INT8，并在顶栏明确展示当前后端与原因。
          

          

            服务端只做两件事：解码浏览器上传的 Float32 向量并写入 seekdb；在检索时调用一次
            collection.hybridSearch()。向量通道与全文通道（ik 分词）的融合由
            seekdb 内的 DBMS_HYBRID_SEARCH 以 RRF 完成，不存在前端拼接两路结果的路径。
          

          
    
            
  • 离线保证：allowRemoteModels=false，模型与 ORT WASM 均为同源静态文件；
    • 
            
  • 增量导入：文档 ID = 来源 + 分块序号 + 文本哈希，内容未变则跳过，变化则 upsert；
    • 
            
  • 索引刷新：导入完成后调用 refresh_index()，刷新完成前搜索保持关闭；
    • 
            
  • 会话状态：localStorage 只保存集合名、计数与刷新时间，不保存文档或向量。
